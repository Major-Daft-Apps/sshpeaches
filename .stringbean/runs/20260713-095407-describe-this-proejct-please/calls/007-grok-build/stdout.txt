**SSHPeaches** is a Kotlin + Jetpack Compose Android app (min SDK 26 / Android 8.0) that functions as a modern, touch-oriented SSH + Mosh client. 

Key capabilities from the committed project (README, developer docs, source tree, and recent changelog entries):
- Terminal sessions (SSH/Mosh) with a custom on-screen keyboard, IME handling, and reconnect/keep-alive support.
- SFTP file browsing + transfers, SCP quick transfers.
- Management screens for **Hosts** (with quick-launch actions), **Identities** (keys + generation/import), **Port Forwards** (local `-L` only), and **Snippets**.
- Quick Connect, favorites, recents, grouped/collapsible lists, QR code share/import (with optional passphrase), widgets, uptime monitoring, diagnostics, and settings (security, theme, terminal prefs).
- Integrates third-party Termux terminal-emulator/view components.
- Firebase (Crashlytics, etc.) for release builds; includes instrumentation/live tests, unit tests, macrobenchmarks, and a small live-ssh-server tool.
- Documentation: user wiki + developer section (Product Blueprint, UI notes, etc.).
- Recent committed work includes OpenSSH config import, SSH/Ed25519/Mosh compatibility fixes, keyboard improvements, and version bumps (current tip around 0.10.x series).

The project uses standard Android/Gradle structure (`app/`, `macrobenchmark/`, `tools/`, `functions/`, `third_party/`, `docs/`, etc.) with ~108 tracked main Kotlin sources under `com.sshpeaches.app.*` (ui/screens, ui/state, data/*, service, uptime, widget, etc.).
